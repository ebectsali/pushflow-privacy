Pushflow

From push to done.

Privacy Policy — Effective: February 26, 2026

Summary: Pushflow stores your settings locally in your browser. We do not collect, transmit, or sell any personal data. Your GitLab tokens and commit data never leave your machine.

1. What Pushflow Does

Pushflow is a Chrome extension that helps developers sync Git commits to TaskFlow ERP task boards. It injects a column into your TaskFlow workspace showing your recent commits, and lets you create tasks from those commits.

2. Data We Collect

None. Pushflow does not collect, store, or transmit any data to external servers owned by us. There is no analytics, no tracking, and no telemetry.

3. Data Stored Locally

Pushflow stores the following data in your browser's local storage (chrome.storage). This data never leaves your browser:

Data Purpose Storage
GitLab URL & Personal Access Token Authenticate with your GitLab instance to fetch commits chrome.storage.sync
GitLab username, project, branch Filter commits relevant to you chrome.storage.sync
TaskFlow workspace & user IDs Auto-detected from the TaskFlow page to make API calls chrome.storage.sync
Picked commit history Track which commits have been created as tasks (prevents duplicates) chrome.storage.local
Task-commit mapping Link tasks to commits for diff image generation chrome.storage.local
Plan Task schedules Temporary storage for task planning (cleared after execution) chrome.storage.local

4. API Communications

Pushflow communicates directly with two services — both configured by you:

4.1 Your GitLab Instance

  • Pushflow fetches commits, diffs, and project info from your self-hosted or cloud GitLab instance.
  • Authentication uses your Personal Access Token (stored locally in your browser).
  • Only read-only API calls are made (commit list, diff data).

4.2 Your TaskFlow ERP Instance

  • Pushflow creates tasks, updates task fields, and uploads diff images to your TaskFlow workspace.
  • Authentication uses your existing browser session cookies (no additional credentials stored).
  • Pushflow only operates on the TaskFlow page you are currently viewing.

4.3 Google Translate (Optional)

  • If you use the translate feature, commit titles are sent to Google's free translation API.
  • This is optional and only triggered when you click the translate button.
Important: Pushflow does NOT communicate with any servers owned by Pushflow or its developers. All data flows directly between your browser, your GitLab instance, and your TaskFlow instance.

5. Permissions

Pushflow requests the following Chrome permissions:

Permission Why
storage Save your settings and task tracking data locally
activeTab Inject the Pushflow column into the TaskFlow page you're viewing
Host permission: your ERP domain Make API calls to TaskFlow for task creation and updates
Host permission: your GitLab domain Fetch commit and diff data from your GitLab instance

6. Data Sharing

We do not share, sell, or transfer any data to third parties. Period.

7. Data Retention & Deletion

  • All data is stored locally in your browser.
  • Picked commit tracking is automatically cleaned up after 30 days.
  • You can clear all extension data at any time by: going to chrome://extensions → Pushflow → "Clear data", or by uninstalling the extension.
  • Uninstalling Pushflow removes all locally stored data.

8. Security

  • Your GitLab token is stored in chrome.storage.sync, which is encrypted by Chrome and synced only to your signed-in Chrome profile.
  • All API communications use HTTPS.
  • Pushflow runs only on pages matching your configured ERP domain — it does not execute on other websites.

9. Children's Privacy

Pushflow is a developer productivity tool and is not directed at children under 13. We do not knowingly collect data from children.

10. Changes to This Policy

If we update this privacy policy, the changes will be posted on this page with an updated effective date. Significant changes will be communicated via the extension's update notes.
